# 星枢文档

星枢（Xingshu）是项目与资源的本地索引中枢。“星”代表彼此独立的项目星群；“枢”代表将群星汇聚、发现、索引、分类和管理的中枢。当前 Git 仓库是第一种支持的项目类型。

## 状态

当前首版支持本地 Git 仓库扫描、主题标签、repo/tag policy、冲突安全、CLI、Axum API 和 Vue WebUI。高级 Git 能力与独立 VCS 属于后续阶段。
